# Contributing

Use the Windows source setup in the [README](README.md). Before a pull request, explain the use case and keep changes focused. Write code, comments, documentation, and commit messages in English.

## Verification

Run the app and exercise the changed workflow with disposable fixtures. For scanning changes, cover exact copies, same-size files with different content, and Unicode file names. For file actions, verify that the keeper remains intact and compare restored content with the original. Include steps you ran and any coverage limits in the pull request.

Use synthetic fixtures and screenshots. Never commit real customer documents, absolute personal paths, audit outputs, credentials, or application caches.

AI-authored commit titles and pull request titles and descriptions must start with `[AI] `.
