# Security policy

For suspected data loss, unintended file access, path handling problems, or other security issues, use GitHub's private vulnerability reporting on the Security tab if it is enabled. If it is unavailable, open a public issue asking for a private reporting channel and omit sensitive details.

Include the affected commit, Windows version, reproducible steps, and expected and actual behavior in a private report. Use disposable synthetic files to reproduce the issue. Do not attach real documents, personal paths, or unredacted reports to a public issue.
